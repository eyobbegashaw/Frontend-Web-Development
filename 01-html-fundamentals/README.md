# 01 - HTML Fundamentals

## 📖 Overview
HTML (HyperText Markup Language) is the standard markup language for creating web pages. This section covers the fundamentals of HTML structure, elements, and semantics.

## 🎯 Learning Objectives
- Understand HTML document structure
- Learn semantic HTML5 elements
- Create forms and handle user input
- Implement accessibility best practices
- Structure content with proper hierarchy

## 💻 Key Topics

### Basic Structure
```html
<!DOCTYPE html>
<html>
<head>
    <title>Page Title</title>
</head>
<body>
    <h1>My First Heading</h1>
    <p>My first paragraph.</p>
</body>
</html>
